# История изменений

## 2.3.0

- Автоматическая стандартная раскладка выбирает минимальное число листов, затем более крупные ячейки, затем меньше частей. Размер текста в символах больше не выбирает профиль.
- Добавлены экспериментальный плотный чёрно-белый режим и цветной режим с 2 или 3 слоями QR. Цветная раскладка выбирается по порядку: меньше листов, крупнее ячейки, меньше цветов/слоёв, меньше частей.
- `inspect --compare` возвращает допустимую раскладку или причину невозможности для каждого режима, даже если выбранный режим не помещается; `version` показывает версию приложения и путь запускаемого файла. `--version` по-прежнему задаёт версию QR.
- Восстановление распознаёт цветные и прежние чёрно-белые передачи и записывает результат только после проверки CRC32, размера и SHA-256.
- Требования не изменены: Node.js 22+, один `.mjs` для создания листов; для восстановления прежние sharp 0.35.5 и zxing-wasm 3.1.5.

- Добавлена инструкция обновления через браузер, Проводник и существующий Git Bash с резервной копией и откатом без обязательного PowerShell.

Цветной режим остаётся экспериментальным: проверка исходных PNG и синтетических JPEG не заменяет испытания с физической камерой. Постоянный коэффициент увеличения вместимости не обещается.
