# Обновление Matrix Sheets до 2.3.0 на корпоративном компьютере

Основной путь ниже использует браузер, Проводник Windows и уже работающий Git Bash. Дополнительная оболочка не требуется. Требования остаются прежними: Node.js 22+, один `.mjs` для создания листов; для восстановления — `sharp` 0.35.5 и `zxing-wasm` 3.1.5. Новые зависимости, Python, компилятор и права администратора не нужны. Если зависимости уже установлены для 2.2.0, повторять `npm ci` не требуется.

## 1. Найдите существующую установку

В Git Bash, где уже работает `msheets`, выполните:

```bash
printf '%s\n' "$MATRIX_SHEETS_ENTRY"
type msheets
```

Каталог, содержащий показанный `matrix-sheets.mjs`, — существующая установка. Ниже пример — `C:\tools\matrix-sheets` (в Git Bash `/c/tools/matrix-sheets`). Используйте свой фактический путь. Откройте этот каталог в Проводнике, вставив его Windows-путь в адресную строку.

Дождитесь завершения активных `pack` и `restore`. Не обновляйте файлы во время операции.

## 2. Скачайте и распакуйте ZIP

В браузере откройте [релиз v2.3.0](https://github.com/kinsyxd/matrix-sheets/releases/tag/v2.3.0) или [последний релиз](https://github.com/kinsyxd/matrix-sheets/releases/latest). У нужной версии разверните **Assets** и скачайте **matrix-sheets-v2.3.0.zip**. Выбирайте этот готовый архив; автоматически добавленные архивы GitHub `Source code` для этих шагов не используются.

В Проводнике откройте «Загрузки», щёлкните ZIP правой кнопкой → **Извлечь всё**. Выберите отдельную новую папку, например `Загрузки\matrix-sheets-v2.3.0-update`, и откройте её после распаковки. Не распаковывайте прямо поверх установленной программы.

В корне готового ZIP лежат файлы приложения; внешней вложенной папки установки нет. Убедитесь, что в распакованной папке есть все семь обновляемых файлов:

```text
matrix-sheets.mjs
README.md
package.json
package-lock.json
terminal.bash
UPDATE-CORPORATE.md
CHANGELOG.md
```

В архиве также могут быть тесты. Для обновления существующей рабочей установки достаточно перечисленных семи файлов.

## 3. Сделайте резервную копию через Проводник

Рядом с существующим каталогом установки создайте отдельную папку, например `C:\tools\matrix-sheets-backup-before-v230`. Если такое имя уже занято, используйте новое имя. Запомните путь.

В существующей установке выделите из списка выше **те файлы, которые уже есть**, и скопируйте их в резервную папку: **Ctrl+C**, откройте резервную папку, **Ctrl+V**. В 2.2.0 новые `UPDATE-CORPORATE.md` и `CHANGELOG.md` могут отсутствовать — это нормально. Убедитесь, что в копии есть как минимум прежние `matrix-sheets.mjs`, `README.md`, `package.json`, `package-lock.json` и `terminal.bash`.

Существующие `node_modules`, `photos`, `out`, другие каталоги листов и восстановленные файлы оставьте на месте.

## 4. Скопируйте обновление в существующий каталог

В распакованной папке выделите **ровно семь перечисленных файлов**, нажмите **Ctrl+C**, перейдите внутрь существующей установки, например `C:\tools\matrix-sheets`, и нажмите **Ctrl+V**. Подтвердите замену совпадающих файлов.

Копируйте сами файлы **внутрь существующего каталога**. Не копируйте папку распаковки как вложенную папку установки. Не заменяйте и не удаляйте весь каталог, `node_modules`, фотографии или собственные данные. Профили Git Bash, PATH и настройки системы менять не нужно.

Если восстановление уже работало в 2.2.0, переходите к проверке: зависимости не изменились. Только если зависимости отсутствуют и вам нужна команда `restore`, перейдите в каталог установки в существующем Git Bash и выполните прежнюю стандартную команду:

```bash
cd "/c/tools/matrix-sheets"
npm ci --ignore-scripts --no-audit --no-fund
```

В примере замените путь своим. Если корпоративная политика блокирует Node.js, npm или компоненты восстановления, используйте существующий согласованный процесс установки. Правила сети и защиты для обновления менять не требуется.

## 5. Проверьте путь, версию и передачу

В уже открытом Git Bash функция `msheets` продолжает использовать прежний путь. При необходимости подключите `terminal.bash` заново из фактического каталога или откройте новый сеанс с вашим существующим способом подключения:

```bash
source "/c/tools/matrix-sheets/terminal.bash"
msheets version
```

Ожидаются версия приложения **2.3.0** и путь к `.mjs` в вашей существующей установке. `--version` задаёт версию QR, а не версию приложения.

Перейдите в удобный рабочий каталог с небольшим файлом `input.txt` или замените `input.txt` своим путём. Используйте новые, ещё не занятые имена каталогов и результата:

```bash
msheets inspect "input.txt"
msheets inspect "input.txt" --compare
msheets pack "input.txt" --out "check-standard-v230"
msheets restore "check-standard-v230" --out "check-restored-v230.txt" --manifest "check-standard-v230/manifest.json"
```

Успешное восстановление должно показать `verified: true`. Для проверки короткой команды из другого каталога повторите `msheets version` после перехода в него.

По желанию отдельно проверьте экспериментальные режимы:

```bash
msheets pack "input.txt" --out "check-dense-v230" --preset dense-experimental
msheets restore "check-dense-v230" --out "check-dense-restored-v230.txt" --manifest "check-dense-v230/manifest.json"
msheets pack "input.txt" --out "check-color-v230" --preset color-experimental --layers 3
msheets restore "check-color-v230" --out "check-color-restored-v230.txt" --manifest "check-color-v230/manifest.json"
```

Эти команды проверяют исходные PNG. Для оценки фотографирования снимите листы своим телефоном и восстановите файл из оригинальных фотографий. Цветной режим экспериментальный; успешное восстановление PNG не подтверждает надёжность физической камеры. Для обычной работы начинайте со стандартного режима.

## Откат через Проводник и Git Bash

Дождитесь завершения активных операций. Откройте резервную папку, выделите сохранённые файлы и скопируйте их обратно **внутрь прежнего каталога установки**, подтвердив замену. Файлы документации, впервые добавленные в 2.3.0, можно оставить: на запуск старой программы они не влияют.

Не удаляйте `node_modules` и собственные данные. Зависимости не менялись, поэтому переустановка для отката не нужна. Существующая функция `msheets` использует возвращённый `.mjs` по тому же пути. При необходимости снова выполните `source` прежнего `terminal.bash`.

Проверьте старую версию обычными командами, которые работали до обновления, например `msheets inspect "input.txt"`. Команда `version` добавлена в 2.3.0 и в старой версии может отсутствовать. Листы экспериментального цветного режима восстанавливайте версией 2.3.0; старая версия не обязана понимать новый формат.

## Необязательная проверка SHA-256 в PowerShell

Этот шаг — дополнительная возможность для компьютеров, где PowerShell разрешён; основной порядок обновления выше его не требует. Если на странице релиза опубликована SHA-256 архива, сравните её со встроенной командой:

```powershell
Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\matrix-sheets-v2.3.0.zip" -Algorithm SHA256
```

Хеш должен совпасть полностью. При несовпадении не используйте архив.
